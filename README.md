If your photo is PNG, either convert it to JPG or update the matching filename in `index.html`.

## Publish with GitHub Pages
1. Create a **new public repository** named `nisha-zinal-invitation` (or another unique name).
2. Upload `index.html`, `.nojekyll`, `README.md`, and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then click **Save**.
6. Wait a few minutes, then revisit Settings → Pages to open the published site.
